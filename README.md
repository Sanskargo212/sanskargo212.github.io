# Alef Art Studio — رزومه و نمونه‌کارها

رزومه‌ی آنلاین **احمد قاسم‌نیا** — برنامه‌نویس، گرافیست و طراح.

🔗 **[alef72.github.io](https://alef72.github.io)**

---

## ساختار

| فایل | توضیح |
|---|---|
| `index.html` | کل سایت در یک فایل — فونت، تصاویر، CSS و JS همگی درون‌فایل (بدون درخواست خارجی) |
| `robots.txt` | اجازه‌ی ایندکس کامل + آدرس نقشه‌ی سایت |
| `sitemap.xml` | نقشه‌ی سایت برای موتورهای جستجو |
| `.nojekyll` | غیرفعال‌کردن پردازش Jekyll در GitHub Pages |

## چرا تک‌فایل

تمام دارایی‌ها به‌صورت `data:` URI درون HTML قرار دارند. نتیجه:

- **صفر درخواست شبکه‌ی اضافه** — نه CDN، نه فونت خارجی، نه تصویر جدا
- بدون زنجیره‌ی وابستگی که رندر را بلاک کند
- قابل ارسال به‌صورت یک فایل مستقل (ایمیل، فلش، آفلاین)

## به‌روزرسانی

فایل `index.html` را جایگزین کنید و push بزنید:

```bash
git add -A
git commit -m "update"
git push
```

انتشار روی GitHub Pages ظرف چند ثانیه انجام می‌شود.
